# Logic-Optimize---Family-time-Ep2
A mod using AI Deepseek to optimize logic physic and AI.

Simply because my chip's too weak to run it,so I used DeepSeek AI to make this mod.
This mod can only be used in Family Time Episode 2,I'm not have ep 3.

If you using,you will need a Mod config manager and BepInEx to mod working.

Link download plugin and mod loader:
Modloader:https://github.com/bepinex/bepinex

Plugin Manager config mod:https://www.nexusmods.com/familytime/mods/4

How to install mod:

Step 1:Download Modloader Bepinex (recommend using latest version) and unzip in Folder game.

Step 2:Run once to obtain the important files.

Step 3:copy file FamilyTimeOptimizer.dll to file C:\Users\<your use>\Documents\<your game file>\BepInEx\plugins
