# Logic-Optimize - Family-time-Ep2
# EN
A mod using AI Deepseek to optimize logic physic and AI.

Simply because my chip's too weak to run it,so I used DeepSeek AI to make this mod.
This mod can only be used in Family Time Episode 2,I'm not have ep 3.

If you using,you will need a Mod config manager and BepInEx to mod working.

Link download plugin and mod loader:
Modloader:https://github.com/bepinex/bepinex

Plugin Manager config mod:https://www.nexusmods.com/familytime/mods/4

How to install mod:

Step 1:Download Modloader Bepinex (recommend using latest version) and unzip in Folder game.

Step 2:Run once to obtain the important files.

Step 3:copy file FamilyTimeOptimizer.dll to file C:\Users\<your use>\Documents\<your game file>\BepInEx\plugins

Run game to apply mod.

If you do not wish to install it due to safety concerns or a fear that your computer might become infected with a virus, you can simply choose not to download it.

# VN
Một bản mod sử dụng AI DeepSeek để tối ưu hóa logic vật lý và AI.

Vì chip máy tính của tôi quá yếu để chạy game, nên tôi đã sử dụng AI DeepSeek để tạo ra bản mod này.
Bản mod này chỉ dành cho *Family Time Episode 2*, không áp dụng cho *Episode 3*.

Để sử dụng, bạn cần cài đặt trình quản lý cấu hình mod (Mod Config Manager) và BepInEx.

Liên kết tải xuống plugin và trình quản lý mod:
Modloader: https://github.com/bepinex/bepinex

Plugin Manager (trình quản lý cấu hình mod): https://www.nexusmods.com/familytime/mods/4

Hướng dẫn cài đặt mod:

Bước 1: Tải xuống Modloader BepInEx (khuyên dùng phiên bản mới nhất) và giải nén vào thư mục cài đặt game.

Bước 2: Chạy game một lần để tạo các tệp tin cần thiết.

Bước 3: Sao chép tệp `FamilyTimeOptimizer.dll` vào đường dẫn: `C:\Users\<tên người dùng>\Documents\<thư mục game>\BepInEx\plugins`

Khởi chạy game để áp dụng bản mod.

Nếu bạn lo ngại về vấn đề bảo mật hoặc sợ máy tính có thể bị nhiễm virus, bạn hoàn toàn có thể chọn cách không tải xuống bản mod này.
